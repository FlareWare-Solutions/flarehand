# Getting help

- Something does not work: read [troubleshooting](docs/troubleshooting.md) and the [FAQ](docs/faq.md),
  then run `python3 skills/flarehand/scripts/doctor.py` and include its output in a
  [bug report](https://github.com/FlareWare-Solutions/flarehand/issues/new?template=bug_report.yml).
- An idea or a missing template: open a
  [feature request](https://github.com/FlareWare-Solutions/flarehand/issues/new?template=feature_request.yml).
- A security problem: follow [SECURITY.md](SECURITY.md). Never post it in an issue.
